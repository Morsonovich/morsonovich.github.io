# morsonovich.github.io

Личный сайт-портфолио (Artem / Morsonovich).

Написан на чистом стеке (HTML5, CSS3, Vanilla JS) без сборщиков и сторонних тяжелых библиотек.

### Основные разделы:
- **Главная / Профиль:** статус, быстрые контакты, аудиоплеер с переключением треков и эффектами.
- **Проекты:** серверные плагины для Minecraft (PaperMC, Spigot, PacketEvents), боты и бэкенд-утилиты с модалками и подробным описанием.
- **Стек & Опыт:** технологии (Java, Kotlin, Rust, Python, Docker, Redis и др.) и таймлайн работы в MintStudio.
- **Терминал:** интерактивная CLI-консоль с командами (`help`, `projects`, `skills`, `contact`, `matrix`, `neko`, `theme`, `clear` и др.).

### Локальный запуск:
Для нормального воспроизведения аудио/видео и работы canvas нужен локальный сервер:

```bash
# Python:
python -m http.server 8000

# или npx:
npx serve
```

После запуска открыть `http://localhost:8000` в браузере.
