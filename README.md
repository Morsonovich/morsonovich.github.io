# morsonovich.github.io

Личный сайт-портфолио — **Артём (Морс / Морсонович)**.

Стек: чистый HTML5, CSS3 и Vanilla JS (ES6+) без сборщиков и сторонних библиотек.

### Структура:
- **01 // Профиль (Bento Dashboard):** карточка разработчика, подробное досье, плеер с визуализатором спектра, сводка по стеку и избранные инженерные кейсы.
- **02 // Проекты (10 кейсов):** каталог разработок с фильтрацией, поиском, метриками архитектуры и фрагментами кода (`TeleCord`, `MintAntiCheat`, `MORSPVO & MTownyRaid`, `MintTowny`, `MorsGuns`, `MetaUpgrades`, `MintAnomalies & MintSpheres`, `MintAlchemy & MintDrugs`, `Rust Data Parsers`, `TG/Discord Bots & FastUI`).
- **03 // Стек и код:** специализация по языкам (`Python`, `Java / PaperMC`, `Rust`, `JavaScript`) и интерактивное окно с примерами кода.
- **04 // MintStudio:** реестр выпущенных плагинов студии и таймлайн (2023–2026).
- **05 // Терминал:** интерактивная консоль `zsh` с автодополнением по `Tab` (`help`, `whoami`, `neofetch`, `projects`, `inspect <id>`, `skills`, `mint`, `cat`, `matrix`, `music`, `theme`).

### Локальный запуск:
```bash
python -m http.server 8000
```
Открыть `http://localhost:8000` в браузере.
